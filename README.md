# A letter of apology

This is a single-page apology website built with the photos already in `css/`.

Open `index.html` in a browser. The page is responsive and uses no build tooling.

## Personalising it

- Update the letter directly in `index.html`.
- Swap any of the six image paths in `index.html` for another photo from `css/`.
- Change the final signature, currently `Yours`, to your name before sharing.

The small JavaScript file only handles gentle scroll-in transitions and the “Back to the beginning” button.
